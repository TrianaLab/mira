# @mira/operator

Not a changelog. Mira's is [`CHANGELOG.md`](../../../CHANGELOG.md) at the root,
hand-written and promoted by `make bump` — which is why `.changeset/config.json`
sets `changelog: false`. This file exists because `changesets/action` opens
`<unit>/CHANGELOG.md` unconditionally when it builds the Version PR body, and
crashes on the one it cannot read.
